# Okpala Chimaobi Samuel — Portfolio

A responsive React + TypeScript + Vite portfolio website with centralized editable content in `src/data/portfolio.ts`.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The app is ready for Vercel or Netlify deployment. Update the placeholder canonical URL, Open Graph image, robots sitemap URL, and favicon when the final domain and social preview are available. The contact form intentionally prevents submission until a provider (Formspree, Resend, EmailJS, Supabase, or a secure backend endpoint) is configured; never add private keys to frontend code.

Edit profile, skills, technologies, projects, experience, education, certifications, services, and social links in `src/data/portfolio.ts`.
